# JointJS+: Font Awesome Inspector <a href="https://www.jointjs.com/jointjs-plus"><img src="../jointjs-plus-badge.svg" alt="JointJS+" width="123" align="right" /></a>

This demo shows a custom element that draws a Font Awesome icon. Drag a shape from the stencil, resize it with the free transform, and pick its icon and color in the inspector.

This demo is also available online at [demos.jointjs.com](https://demos.jointjs.com/font-awesome-inspector/).

## Available Versions

- [TypeScript](./ts/)
