# JointJS+: Tree Stencil <a href="https://www.jointjs.com/jointjs-plus"><img src="../_assets/jointjs-plus-badge.svg" alt="JointJS+" width="123" align="right" /></a>

The Tree Stencil demo brings the power of the JointJS+ TreeLayout to the Stencil allowing users to create a directory of Stencil elements which is both expandable and collapsible.

## Available Versions

- [JavaScript](./js/)
- [TypeScript](./ts/)
