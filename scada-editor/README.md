# JointJS+: SCADA Editor <a href="https://www.jointjs.com/jointjs-plus"><img src="../jointjs-plus-badge.svg" alt="JointJS+" width="123" align="right" /></a>

An editor of a SCADA plant diagram: tanks, pumps, valves, joins, zones and the pipes between them. Drag equipment and pipes from the palette onto a scrollable, zoomable canvas and move them around. A toolbar button switches the editor into the runtime mode: the diagram can't be changed any more, the plant runs (a mock sending random updates of its data) and the equipment is operated with its controls.

## Available Versions

- [TypeScript](./ts/)
- [React](./react/)
