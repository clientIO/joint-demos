# JointJS+: Data Modeling <a href="https://www.jointjs.com/jointjs-plus"><img src="../jointjs-plus-badge.svg" alt="JointJS+" width="123" align="right" /></a>

Let your users design database schemas visually, right inside your web app. This demo is a complete data-modeling experience: tables with typed columns, keys, and indexes are drawn as an entity-relationship diagram, relations are created by dragging between columns, and the schema stays in sync with real SQL — the app runs an actual database engine in the browser (SQLite and Postgres), imports existing SQL files, and exports dialect-correct DDL.
